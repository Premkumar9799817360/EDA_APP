# 📊 EDA - Exploratory Data Analysis  

## 🧠 About  
This project aims to **automatically perform advanced Exploratory Data Analysis (EDA)** on any dataset using the **Pandas Profiling** library.  
It uncovers hidden patterns, relationships, anomalies, and presents them in a visually rich and easy-to-understand report.

## ⚙️ What This Project Does  
- Upload any **CSV dataset** 📁  
- Automatically generate a **Pandas Profiling Report**  
- Get detailed insights including:  
  - Dataset overview and variable types  
  - Missing values and distributions  
  - Correlations and relationships  
  - Statistical summaries and key metrics  
  - Heatmaps and scatter plots  

This is a complete **end-to-end data analysis project** powered by:  
- 🧮 **NumPy**  
- 🐼 **Pandas**  
- 📘 **Pandas Profiling** (for generating reports)
-  🖥️ **Streamlit UI** – simple, interactive, and responsive interface

## 🚀 How to Use  
1. Upload your **CSV file**.  
2. Click **Generate Report**.  
3. The app automatically displays your complete **EDA Report** — including data types, correlations, and visual insights.
